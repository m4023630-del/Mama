КАК ЗАПУСТИТЬ САЙТ
1. Загрузите index.html на любой статический хостинг (например, GitHub Pages или Netlify).
2. Получите публичную ссылку вида https://...
3. Откройте qr_code.png и замените QR-код на QR с вашей готовой ссылкой.
4. Распечатайте QR-код или отправьте маме.

Важно: текущий QR-код содержит текст YOUR-SITE-URL-HERE, потому что публичную ссылку на сайт нельзя создать без аккаунта/хостинга.
